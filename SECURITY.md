# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use [GitHub Security Advisories](https://github.com/Has-X/Sensitivity/security/advisories/new) to provide a private report.

If the advisory form is unavailable, contact the maintainer through the address listed in the repository profile. Do not include device serial numbers, validation tokens, private ROM URLs, or complete raw recovery responses in a report.

## Scope

Reports about token exposure, unsafe wipe behavior, malformed protocol handling, USB claims, release artifacts, dependency vulnerabilities, or CI permissions are in scope.

## Response

Reports are triaged privately. Include a minimal reproduction, affected version or commit, platform, and redacted logs. We will coordinate a fix and disclosure timeline with the reporter.
